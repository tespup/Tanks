5. js/audio.js
Роль: Весь звук и музыка.

Sound
Поля: ctx, master, noiseBuf, muted.

Методы:

init() — создаёт AudioContext (+ webkitAudioContext), master.gain = 0.40, шумовой буфер 1 секунда белого шума.

resume() — ctx.resume() если suspended.

tone(f0, f1, dur, type, vol, delay) — тон с задержкой от currentTime.

toneAt(f, dur, type, vol, when) — тон в момент when.

toneAtSweep(f0, f1, dur, type, vol, when) — тон с экспоненциальным свипом частоты.

noise(dur, freq, vol, delay, type) — шум с lowpass/highpass.

noiseAt(dur, freq, vol, when, type) — то же в момент when.

kickAt(w) — 150→44 Гц sine + шум.

snareAt(w) — шум highpass 1800 + triangle 210.

hatAt(w) — шум highpass 7200.

SFX-методы (все вызывают tone/noise):
shoot, enemyShoot, bossShoot, turretShoot, brick, crack, steel, shieldHit, pop, sand, digStart, buildDone, buildFail, modeSwitch, menuMove, menuSelect, menuBack, boomSmall, boomBig, hitArmor, stun, powerup, upgrade, commander, armorUp, spawn, respawn, teleport, bossDeath, bossSiren, levelClear, victory, gameOver, life.

Музыкальные данные
CHORD_TYPES — maj, min, dim, sus, maj7, min7, dom7 (массивы полутонов).

BASS_PAT — A, B, C, D — 8-ступенчатые паттерны.

ARP_PAT — 3 паттерна арпеджио по 8 ступеней.

DRUM_PAT — 3 паттерна: {kick[], snare[], hat[]}.

MELODIES — 10 мелодий. Поля: name, bpm, bass, arp, drum, chords[[root, type]...], lead[32].

MUSIC_STEPS = 32.

Music
Поля: idx, step, nextTime, stepDur, active, enabled.

Методы:

midi(m) — MIDI → Гц (440 * 2^((m-69)/12)).

start(idx) — выбирает мелодию, сбрасывает step, вычисляет stepDur = 60/bpm/2, nextTime = currentTime + 0.12, active = true.

stop() — active = false.

update() — секвенсор. Пока nextTime < now + 0.32:

вычисляет s = step % 32, bar = s/8, sb = s%8;

играет лид (M.lead[s]), бас (BASS_PAT), арпеджио (ARP_PAT), барабаны (DRUM_PAT);

step++, nextTime += stepDur.

Роль: Игровые сущности.

Tank
Конструктор (x, y, dir, isPlayer, type, playerIndex):

инициализирует все поля: speed, hp, maxHp, cooldown=0.5, shieldTimer=0, frozen=0, spawnTimer (0.8 игрок / 1.0 враг), spawnMax, trackPhase=0, muzzle=0, dead, deathHandled, blocked, blockTime, flash, forceStar, hitFlash, onSand, mode='tank', buildT=0, buildTotal=BUILD_TIME, buildTile=null, aiTimer, shootTimer, tpCool=0, ghost=0, mineCool=0, stealthT, matkaT=MATKA_INTERVAL.

Методы:

rect(), touchRect(), center().

tileAt(gm, x, y) — тип тайла.

canOccupy(nx, ny, gm) — проверка границ, тайлов, танков. Игрок со силой ≥4 — вездеход (вода проходима). ghost > 0 — игнор танков.

alignPerp(gm) — выравнивание по сетке перпендикулярно движению.

17. ПОТОКИ ДАННЫХ
Инициализация
index.html грузит скрипты.

main.js вызывает loadBinds, pollPads, applyLevelTheme, buildOverlays, generateLevel(1).

applyLevelTheme → makeClassicPalette → buildTileSprites → все paint*.

UI.active = true, UI.screen = 'main'.

Игровой цикл
requestAnimationFrame(loop).

Input.poll() — читает клавиатуру/геймпад/виртуальные кнопки.

Если UI.active — меню, иначе game.update(dt).

render(now/1000) — вся отрисовка.

Очистка justPressed.

Ввод → действие
keys / pads / vInputState обновляются слушателями.

Input.poll() маппит BINDS → Input.st[pi].

Tank.updatePlayer читает Input.st[pi] и вызывает tryMove, tryShoot, gm.startBuild, gm.toggleMode, gm.placeMine, gm.teleportPlayer.

Стрельба
Tank.tryShoot → new Bullet → gm.bullets.push.

Bullet.update — движение, коллизии.

gm.resolveBulletHits — пуля vs пуля.

gm.bullets = gm.bullets.filter(b => !b.dead).

Смерть врага
Bullet.update → e.hit() → 2.

gm.onEnemyKilled(e) → очки, killStats, взрыв, drop, checkWin.

gm.enemies = gm.enemies.filter(e => !e.dead).

Уровень пройден
checkWin → levelClearPending = true, clearT = 5.

updatePlaying → clearT <= 0 → state='levelclear', transitionT=5.8, +500.

update → transitionT <= 0 → level++, state='playing', startLevel.

Рендер
render(time) → фон, поле, сущности, эффекты, панель, экраны, UI, overlays.
